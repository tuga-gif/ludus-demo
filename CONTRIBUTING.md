# Contributing

Contributions to the public interface, accessibility, local library, themes, sample catalogue and local backup validation are welcome.

Use the development guide in `docs/DEVELOPMENT.md` and keep changes small enough to review. Include a description of the behaviour changed and how it was checked. Use fictional fixtures in tests.

Do not attach personal profiles, backups, credentials or private launcher files to issues or pull requests. This edition has no integration with production Ludus services.

Keep the public scope in `docs/PUBLIC_SCOPE.md` accurate. New features should work locally and remain useful without private services.
