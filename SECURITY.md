# Reporting an issue

This repository is the standalone Ludus demo. It does not include the official launcher's private code, accounts or online services.

For a security issue, contact the Ludus team privately through a support ticket in the [official Discord](https://discord.gg/XRqMF8xcPA). Describe the affected demo version, the expected behaviour and a minimal example using fictional data. Do not include passwords, tokens, personal backups or private application files.

Please avoid posting exploit details or personal data in public issues before the team has reviewed the report. Ordinary interface bugs and feature requests can be reported in GitHub issues.

The demo binds to loopback only. Keep that boundary when developing it. Do not expose its local server to a public network or add connections to production Ludus services.
